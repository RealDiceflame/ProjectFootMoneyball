PROJECT FOOT MONEYBALL - START HERE

This download contains versions for Windows and macOS. You only need to
extract and use the ZIP that matches your computer.

WINDOWS
1. Open ProjectFootMoneyball-Windows.zip.
2. Extract everything.
3. Double-click Project Foot Moneyball.exe.

MAC
1. Click the Apple menu in the top-left corner and choose About This Mac.
2. If it says Chip: Apple M1, M2, M3, or another M-series chip, open:
   ProjectFootMoneyball-macOS-Apple-Silicon.zip
3. If it says Processor: Intel, open:
   ProjectFootMoneyball-macOS-Intel.zip
4. Extract the selected ZIP and open Project Foot Moneyball.app.

If macOS blocks the app the first time, Control-click the app, choose Open,
and then choose Open again.

You can delete the two unused platform ZIPs after your application opens.
