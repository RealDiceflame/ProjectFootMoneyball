How Age Curve v1 works

A transparent baseline we can improve

1

Recent form

The latest three seasons receive 5:3:2 weights, with partial seasons contributing less.

2

Position aging

Year-over-year changes from the same player and position estimate improvement or decline at the next age.

3

Expected games

Recent availability is blended with a healthy-season baseline instead of assuming everyone plays all 17 games.

4

Uncertainty

Player history and the same-position age group create the displayed one-standard-deviation range.

This first version intentionally does not guess coaching changes, depth-chart usage, offensive efficiency, or strength of schedule. Those become separate, visible model inputs rather than hidden adjustments.
